1. Move existing SQL, column lists and raw-row mapping without changing statements or parameters. Adapt only imports and ownership location.
2. Preserve registration upsert identity on (principalSubject, agentKey), optional display-name behavior, enabled status, getById undefined result, and safe error mapping.

4. Keep an internal transaction-local ensureSession(database, input). Expose the contract-level ensure/get/delete repository separately. The internal helper is for the work adapter to reuse on its own transaction client.
5. Characterize current optional sessionTypeKey/sessionTypeVersion behavior instead of inventing new storage. No DDL edit or automatic round-trip claim is authorized.
6. Add query-double tests for parameters and result/error normalization. Do not mistake these for real owner-race/constraint tests.
