## Implementation steps

1. Preserve all existing repository signatures, DTO field names, optional fields, absence sentinels, WorkStatus values and RepositoryError codes. Do not rename the domain operations to ORM CRUD.
2. Add PersistenceRepositories and PersistenceProvider exactly as C02. A complete provider returns registrations, sessions, work and one dispose method. Do not add raw connections, generic queries, ORM entities, transactions or adapter-discriminator branches to the public contract.
3. Document one-store consistency: a provider bundles compatible repositories over the same logical database. Work submission owns its session-plus-work atomic unit.
4. Write compile-time/shape fixtures using the existing interfaces. Do not use any/unsafe assertions to make partial providers pass; implement explicit unused-method stubs that throw in test fixtures.
5. Create a migration list for current createPostgres* exports and isJsonbSafe names. Do not remove the old runtime exports yet; their consumers are migrated in later packets.
6. Freeze the decision in the handoff. Subsequent workers may request a contract amendment but may not invent their own competing provider type.
