## Implementation steps

1. Implement createPostgresPersistenceProvider returning registrations, sessions, work and dispose. Construct every repository over the same owned pool. Hide the pool from the return type and object.
2. Validate adapter-specific options before resource allocation. Translate neutral selection keys url/workLeaseSeconds/maxConnections into existing PostgreSQL construction values.
3. Add the allowlisted configured loader inside adapters. Resolve absent provider to postgres only there. Use lazy import so loading the neutral root or disabled host never evaluates pg.
4. Reject unknown provider names and unsafe configuration before allocation. Do not interpret the provider string as a path or package to import. Do not silently fall back after a selected adapter fails.
5. Ensure partial provider construction releases an acquired pool and preserves a safe error. Make provider disposal idempotent and terminal; owned resources close once.
6. Keep adapter entrypoints explicit. Do not re-export this provider or registry from the neutral root, and do not add future-driver placeholder folders.
