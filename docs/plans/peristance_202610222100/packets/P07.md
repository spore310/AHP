## Implementation steps

1. Implement one private operation scope with run(operation) and dispose(). It receives only an owned cleanup function, not pg/ORM types or a vendor selector.
2. On first dispose, close admission synchronously, then await admitted operations with all-settled semantics, then invoke cleanup exactly once. Cache the final promise including its rejection.
3. Contain synchronous adapter throws and async failures. Keep query results/errors associated with their callers; a failed query must not prevent cleanup or be rethrown as a duplicate disposal failure.
4. After closing begins, reject new calls without invoking the adapter. Do not reopen on cleanup failure or auto-retry cleanup. Do not invent cancellation or a bounded drain guarantee.
5. Normalize unexpected exceptions to safe RepositoryError output. Preserve recognized codes without echoing vendor details; no duck-typed SQL error classification belongs here.
6. Use deferred promises to test race order deterministically. Ensure promise tracking itself creates no unhandled rejected promise.

## Adversarial check

A second dispose must not resolve while the first is waiting for a parked operation; a failed operation must not leave the cleanup skipped.
