## Implementation steps

1. Build a repository conformance fixture API around PersistenceProvider, not Pool or SQL. Keep setup hooks such as seed/expire controlled in test fixture contracts, never in production repository interfaces.
2. Run contract/substitution scenarios with an independent fake provider through the actual neutral facade and WorkService/AgentDirectory wiring. Preserve all existing host wire tests.
3. Cover shape/sentinel parity, parameter forwarding, this binding, safe error normalization, operation draining and two provider instances with isolated state.
4. Cover semantic scenarios for idempotent submission, ownership, targeted claims, competing claims, stale/expired lease handling, bounded retries, terminal cancellation and dependent-work deletion. Label fake-backed results as model behavior only.
5. Add PostgreSQL query-double/transaction tests and the reusable real-database fixture entrypoint. A real test run requires separately authorized dedicated infrastructure. Never create/provision/migrate merely because an environment variable exists.
6. Add dependency tests to inspect transitive local production imports and disallow concrete adapter/vendor reachability from the neutral root and domains. Simple text search is a supplement, not the whole graph check.
7. Attach an explicit skipped/blocked reason to real DB scenarios. No pass-with-no-tests, skipped-green completion claim, or mock claimed as concurrency proof.
