## Namespace-sensitive key inventory (H4-09)

Scope is carried by the storage adapter instance. One namespace is one
logical store and, with PostgreSQL, one schema. Nothing below resolves a
namespace from request input or from mutable process state.

| Key or state | Where | Boundary |
| --- | --- | --- |
| Session URI, unique among non-retired sessions | `sessions_nonretired_uri_uidx` | Per schema |
| Session and resource incarnations | `sessions`, `canonical_resources` primary and unique keys | Per schema |
| Agent registration `(domain, subject, key)` and its capacity count | `agent_registrations`, `work_items_active_agent_idx` | Per schema. Capacity is not aggregated across namespaces. |
| Work idempotency `(session, kind, requestKey)` | `work_items` unique key | Per schema |
| Session owner and ownership epoch | `sessions.owner_host_id`, `ownership_epoch` | Per schema |
| Host lease | Advisory lock keyed by `(lease_slot, host_state relation)` | The relation differs per schema |
| Reservation locks | Advisory locks keyed by the `host_state` relation | Per schema |
| Membership, namespace binding, policy and authority revisions | `host_members`, `host_namespaces` | Per schema |
| Native sequence | `host_server_seq`, `host_state.server_seq` | Per schema |
| Durable events and retention | `host_events`, `host_event_retention` | Per schema |
| Event wakeup | `NOTIFY ahp_host_events` | Database-wide wakeup only. Each reader polls its own schema, so a foreign wakeup causes one empty read. |
| Recovery list | `listRecoverable` filtered by owner | Per schema and per owning host |
| Retirement and purge | Locked session read, then deletes by session incarnation | Per schema and per owning host |
| Live session registry, authorization registry, agent directory | One per `createAHPServer` | Per server instance |
| Router location cache, captured handshakes, sticky call routes | One per `createAHPServer` and per connection | Per server instance |
| Order gate, view queues, catalogue cursors | Per connection | A cursor is refused on another connection |

Reviewed against: the lifecycle test that runs two namespaces in one process,
the portable coordination suite, the live run with two schemas, and the
refused cross-namespace host.
