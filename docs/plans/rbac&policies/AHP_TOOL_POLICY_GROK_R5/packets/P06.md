## Implementation steps

1. Implement explicit assign/revoke service methods requiring trusted issuer context and registered assignment rules. No generic mutation through session actions, role strings or owner status alone.

2. Limit subject class, exact policies, scope relationships, maximum duration and redelegation depth. Validate parent lineage; reject cycles, overbroad roles/scopes and expiry beyond the authority basis.

3. Store grants by actual actor/domain/instance, not shared agent implementation. Same harness for two users must still have different contexts and separate parent authority. Human challenge approval never converts an agent into a human.

4. Increment local revisions on grants, policy bindings, relationship and instance changes. Invalidate both positive and negative decisions, assignments and pending continuation stamps through a single event seam.

5. Provide bounded, synchronous freshness verification at final local admission. Resolve external state through injected ports with explicit validity/expiry/invalidation promises; do not pretend a remote async evaluation is atomically current forever.

6. Check expiry on access and bounded maintenance. Per-host transient grants disappear on restart by default. Do not add SQL/durable restoration. Retain current owner-only work guards unchanged.
