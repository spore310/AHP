## Implementation steps

1. Implement the project-specific version-2 envelopes/methods in D3, separate from native AHP 1.0.0. Safe native initialization has no automatic protected root subscription; capabilities negotiation reveals no tool inventory.

2. Return only current allowed assigned descriptors and safe operation/challenge affordances. Requests carry selectors, never authoritative roles, owners, grants, providers or policy decisions.

3. Use private advertise request/response for exact accepted descriptors. Stage handlers first; activate only after exact response, current revision/instance and connection checks. Keep prior handlers when acknowledgement fails.

4. Dispatch records a bounded invocation and returns promptly; status serves only the current authorized caller. Retain output under finite TTL/bytes/counts; cancel is authorized/cooperative. Defer valid challenge operation to P13 but reject unsupported required challenges.

5. Add richer dispatchTool/resumeTool-facing DTOs; compatibility callTool returns output only on completion or throws a typed pending-challenge condition. No silent resubmit after lost response or timeout. Use bounded polling/backoff in the convenience API.

6. Migrate all old wire aliases to the same protected dispatcher or reject them explicitly. A legacy client unable to support restricted metadata gets extension-required, not a full-manifest fallback.

7. Use injected authenticated transport; verify borrowed/owned shutdown behavior. Runtime argument validation for v2 complete/invoke remains exact and does not grant arbitrary notification bypass in the connection pump.
