## Implementation steps

1. Separate client connection/invocation logic from local implementation routing while moving it beneath toolExecution. Follow index/types/helpers layout; do not move code into new index implementations.

2. Keep one implementation. Old @toolClient imports re-export the new runtime; they cannot retain a parallel broker or silently default to an old unchecked path.

3. Preserve staged handlers, exact descriptor acknowledgement, failure rollback, concurrent-join serialization, timeouts and shutdown before security behavior changes in later packets.

4. Introduce the typed transport injection seam using the installed SDK interface inspected in P00. Specify who owns shutdown of borrowed versus constructed transport. Keep server/default-platform runtime imports out of the neutral/client entrypoint; use an explicit or lazy Node transport adapter. Do not assume browser arbitrary headers or add query-token authentication.

5. Keep this packet behavior-preserving and mark it transitional. Protected egress/enforcement is not finished by this rename. Scope-limit existing tests to import/move regressions; do not weaken assertions.
