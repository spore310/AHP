## Lifecycle and bounds

1. Validate finite limits and input/callId bounds before admission; capture bounded plain JSON without getters/cycles/prototypes or post-check mutation. Preserve legitimate JSON keys (including constructor/prototype); do not reuse authorization's reserved-policy-key rejection for general payloads. A small action-owned bounded copier will reuse the established descriptor-based traversal pattern, returning frozen copied JSON and its encoded byte size. No general utility module or JSON.parse bypass.
2. Reserve capacity before any trusted async callback. Resolve/capture initial context, validate input schema, coarse current access, then instantiate action. Coarse deny reaches no custom hooks/factory. Supplementary authenticate cannot grant rights; custom validate may return only void or normalized input. Reject malformed normalization results. Recapture/revalidate normalized data, resolve exact final route/context, enforce pinned identity, full policy and currentness before prepare and execute.
3. Prepare uses frozen canonical input/context and onCleanup. Each acquisition registers cleanup immediately. Register callbacks only while prepare is live; late registration after settlement is rejected. Execute receives prepared or undefined. Output is bounded/captured/schema-checked before success, with aggregate bytes reserved while cleanup retains it. Currentness is checked again before result publication. No state projector or arbitrary action dispatch.
4. Actual action settlement owns cleanup. Action cleanup precedes registered callbacks in reverse order; attempt every callback after failures, exactly once. Preserve primary safe failure code/phase; separately count/sanitize cleanup failures. Successful effect followed by cleanup failure returns an explicit post-effect failure, never triggers retry. No arbitrary exception text/stack/input/identity in public errors.
5. cancel/overall timeout/async-hook deadline resolves client-facing result promptly and aborts cooperatively, but never cleans up resources still used by an unsettled hook/execute. Retain job capacity and output bytes until actual settlement and cleanup. Late hook fulfillment cannot proceed to another phase, execute, or publish success. result may be an early cancellation outcome; settled supplies final sanitized cleanup diagnostics after ownership drains. No result replay cache in P08: completed outputs are released from dispatcher storage; caller-held result retention is outside this owner.
6. shutdown synchronously stops admission, cancels active calls and waits up to a configured finite drain budget, then reports remaining draining count. It never loses unsettled job ownership; later settlement still cleans up and releases capacity. No forced termination or promise of reversing effects. Timers/listeners are disposed after their phase/job; no permanent per-frame/per-call listener accumulation. Clock must stay finite; sample it before a final synchronous currentness callback, then only inspect owned closed/abort state.

Finite defaults/hard ceilings will be declared in dispatcher types: maxInFlight 64/1024; input/output bytes 1MiB/16MiB; JSON depth64/128 and keys131072/1048576; aggregate retained output16MiB/256MiB; overall timeout30s/120s; hook timeout5s/60s; shutdown wait5s/60s. All overrides must be positive finite safe integers at or below ceilings. They are local runtime budgets, not permission limits. Inject clock; tests use fake timers and controlled promises.

## Reviewed API precision

Full authorization returns decision plus AuthorityRevisionStamp. The runner recaptures/validates the full stamp into final context before prepare/execute; caller/executor/route must match. Initial context authority is provisional for coarse and supplementary hooks, never sufficient to prepare. Currentness must be invocation/evaluation-specific: P09 retains the entire LocalDecisionStamp (expiry/external/grant evidence) privately in its per-call port; no shared mutable last-decision slot or treating AuthorityRevisionStamp as complete freshness. Every implementation binding discriminant/id/artifactRef must match the captured registration. The origin resource incarnation stays pinned across normalization.

Public handle result is the client-facing outcome; settled is the final lifecycle outcome including cleanup diagnostics. Failures expose only fixed code, phase, effectPossible and cleanup failure count, not exception text or private identity. Success output is delivered only after cleanup and currentness. Dispatcher keeps no completed replay cache; duplicate active call ids reject, and P09/P11 wire correlation owns completed request reuse policy. Optional upstream AbortSignal links disconnect/cancel, with listener removed at settlement.
